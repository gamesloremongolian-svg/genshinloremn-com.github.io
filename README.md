
# Genshin Lore Mongolian

Монгол хэл дээрх Genshin Impact-ийн ертөнц, дүрүүд, түүх, нууцлаг үйл явдлыг судлан хүргэх вебсайт.

## Үндсэн боломжууд

- Lore нийтлэл унших
- Нийтлэл хайх, ангилах
- Дүрүүдийн мэдээллийн сан
- Админ нийтлэл оруулах
- Хэрэглэгчийн бүртгэл
- Сэтгэгдэл бичих
- Responsive дизайн

## Зорилго

Genshin Impact-ийн албан ёсны мэдээлэл, тоглоом доторх баримт болон онол таамгийг ялгаж, Монгол хэлээр хүргэх.
