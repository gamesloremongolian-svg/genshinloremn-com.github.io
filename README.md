# Games Lore Mongolian

Монгол хэл дээрх тоглоомын ертөнц, дүрүүд, lore, домог, мэдээний сайт.

## GitHub Pages дээр байрлуулах
1. ZIP файлыг задлана.
2. `gamics-master` хавтасны ДООТОРХ бүх файл, хавтсыг GitHub repository-ийн үндсэн түвшинд байршуулна.
3. `index.html` файл repository-ийн root түвшинд байгаа эсэхийг шалгана.
4. Repository → Settings → Pages → Deploy from a branch → `main` / `root` сонгоод Save дарна.

## Тайлбар
Одоогийн зурагнууд нь эх Gamics загвараас үлдсэн түр placeholder зургууд. Genshin Impact болон бусад тоглоомын албан ёсны/зөвшөөрөлтэй зургаар солих боломжтой. Цэс, хайлт, responsive layout ажиллана.
