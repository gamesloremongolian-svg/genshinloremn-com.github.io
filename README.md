# Games Lore MN

Монгол хэл дээрх тоглоомын ертөнц, дүрүүд, үйл явдал, далд утга болон lore судалгааны нэгдсэн архив.

## Төслийн зорилго

Games Lore MN нь Genshin Impact, Wuthering Waves, ANANTA, Aniimo, Delta Force зэрэг тоглоомуудын түүх, дүр, ертөнцийн мэдээллийг Монгол хэлээр цэгцтэй хүргэх зорилготой.

## Сайтын үндсэн боломжууд

- Тоглоом тус бүрийн lore болон ертөнцийн мэдээлэл
- Нийтлэлийн жагсаалт, хайлт, ангилал
- Genshin Impact дүрүүдийн мэдээллийн сан
- Хэрэглэгчийн бүртгэл болон нэвтрэлт
- Premium контентын сервер талын функцүүд
- Гар утас, компьютерийн дэлгэцэд зохицсон загвар

## Файлын зохион байгуулалтын дүрэм

1. Нүүр болон шууд URL-аар нээгдэх үндсэн HTML хуудсуудыг root эсвэл одоо ашиглаж буй тоглоомын хавтсанд хадгална.
2. CSS файлуудыг зөвхөн `assets/css/` дотор байрлуулна.
3. JavaScript файлуудыг `assets/js/` дотор байрлуулна.
4. Зургийг `assets/images/` дотор тоглоом, дүр, бүс нутгаар ангилна.
5. Автомат шинэчлэлтийн скриптийг `scripts/` дотор, workflow-г `.github/workflows/` дотор хадгална.
6. Supabase SQL болон Edge Functions-ийг `supabase/` дотор хадгална.
7. Файл устгахын өмнө бүх HTML, CSS, JavaScript болон өгөгдөл доторх холбоосыг шалгана.
8. Одоо ашиглагдаж буй URL болон redirect хуудсуудыг хадгална. Файлын зам өөрчлөх бол холбогдох бүх замыг хамтад нь шинэчилж шалгана.

## Өгөгдлийн шинэчлэлт

Genshin дүрийн мэдээллийг `characters-auto.json` файлд хадгалдаг. Шинэчлэлтийн скрипт нь `scripts/update-characters.mjs`, автомат workflow нь `.github/workflows/update-characters.yml` дотор байрлана.

## Нийтлэл

Нийтлэлийн өгөгдлийн үндсэн JavaScript файл: `assets/js/posts.js`.

## Байршуулах орчин

- GitHub Pages
- HTTPS
- Supabase — хэрэглэгчийн бүртгэл болон сервер талын Premium ажиллагаанд

## Хөгжүүлэлтийн зарчим

- Эхлээд одоо байгаа ажиллагааг шалгана.
- Өөрчлөлт бүрийн дараа холбоос, зураг, скриптийн замыг шалгана.
- Нууц түлхүүр, service-role key болон API secret-ийг нийтэд нээлттэй HTML/JavaScript файлд хадгалахгүй.
- Нийтлэл дотор албан ёсны баримт, тоглоомын доторх баримт, редакцын тайлбар, онолыг ялгаж тэмдэглэнэ.
